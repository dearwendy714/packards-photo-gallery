GRAFFITI USA CAROUSEL — HEYZINE

This is a working carousel template. It needs your original photos before it can display the gallery.

To add images:
1. Put photo files (e.g. car01.jpg, car02.jpg) in this folder.
2. Edit photos.json to list them, e.g.:
[
  {"src":"car01.jpg","alt":"Blue vintage car","caption":"A classic on display"},
  {"src":"car02.jpg","alt":"Museum memorabilia","caption":"Memories from Graffiti USA"}
]
3. Upload the folder contents to a static host such as Netlify Drop (https://app.netlify.com/drop).
4. Paste the resulting public https URL into Heyzine > Interactions > Web > Link > Web address, and click Apply.
5. Save the Heyzine flipbook, then test the buttons on a phone and computer.

The gallery is manual only: large Previous/Next buttons, no autoplay, accessible keyboard arrows.
